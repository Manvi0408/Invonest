# Integration logos (optional)

`IntegrationsHub3D` draws a tile for each integration on a canvas — white face
with the brand mark in the brand colour (Slack gets its real pinwheel).

To use official artwork instead, drop a **square PNG with a transparent or white
background** here, named after the slug. It is picked up automatically on next
load; no code change needed.

    gmail.png  stripe.png  razorpay.png  hubspot.png  salesforce.png
    zoho.png   quickbooks.png  slack.png  outlook.png  xero.png

512×512 is plenty. If a file is missing the generated tile is used, so partial
sets are fine.

Grab official assets from each vendor's brand/press page and follow their brand
guidelines — that's why they aren't vendored here.
